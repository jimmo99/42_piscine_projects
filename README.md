# 42 Urduliz — Piscine Projects

This repository contains the complete collection of projects, exercises, and challenges I developed and submitted during the **42 Piscine** at **42 Urduliz**.

---

## 📌 Context & Overview

The **Piscine** is an intensive 26-day boot camp designed to immerse candidates in low-level programming, algorithmic problem-solving, and peer-to-peer learning under high pressure and strict deadlines.

This repository serves as a faithful snapshot of my work during those 26 days.

> **Note on code quality & outcomes:**  
> All files in this repository reflect the **exact state in which they were submitted**. They may contain bugs, edge-case oversights, or unoptimized solutions.  
> 
> Not everything here received a passing grade: individual daily modules, weekend group challenges (**Rush**), and final projects (**BSQ**) are included as-is, whether they passed evaluation or not. The goal of this repository is not to present a curated portfolio of flawless code, but to document the authentic learning curve, dedication, and progress achieved throughout the experience.

## 🛠️ Norminette & Coding Constraints

All C projects during the Piscine must adhere to the **42 Norm**:
- Maximum of 25 lines per function.
- Maximum of 5 functions per `.c` file.
- Strict variable declaration rules and forbidden constructs (`for`, `do...while`, `printf`, etc.).
- Limited standard library functions (frequently restricted solely to `write`).
